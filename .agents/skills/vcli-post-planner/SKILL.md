# vcli: Post Planner

Plan the article before creating or filling the draft.

## Output

Provide:

1. Working title
2. Target reader
3. One-sentence promise of the post
4. Why this article follows the chosen prior post or series
5. Outline with section goals
6. Candidate code examples, screenshots, or diagrams

## Rules

- Keep the outline practical and repo-grounded.
- If continuity with a prior post matters, say where that prior post should be mentioned.
- Ask for user confirmation on title and angle before moving to drafting.
